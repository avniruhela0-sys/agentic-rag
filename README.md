# Agentic RAG Research Agent

A self-correcting research agent using LangGraph, RAG, and LLM-as-Judge.

## Tech Stack
- Python 3.9+
- LangGraph / LangChain
- ChromaDB (Vector Store)
- OpenAI API
- Tavily (Web Search)

## Setup
1. Clone repository
2. Create virtual environment: `python3 -m venv venv`
3. Activate: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt` (coming soon)
5. Add API keys to `.env`
